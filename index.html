01  /  About Ussari

Three founders.
One foundation.

Ussari — from the Punjabi Usaari, to build from the ground up — is a software engineering and AI studio built on a simple belief: next-generation technology should not be reserved for enterprise budgets. It should be within reach of every business in Pakistan.

The studio was founded by three friends with one conviction. The mark says it plainly: three interlocking blocks, one structure. No single founder carries it alone.

“We’re not here to sell hype. We’re here to pour the foundation — solid, engineered, built to carry real weight.”

MISSION — To make cutting-edge software and AI infrastructure locally accessible and affordable.

Local, not outsourced

A Pakistan-based team that understands local operating realities, budgets, and pace of business.

Engineering-first

Founders who build, not just sell — every engagement is led by the people writing the code.

Priced for reality

Enterprise-grade delivery without enterprise-only pricing — cutting-edge tech, made affordable.

Built to last

Structural precision in the product, not just the brand — systems engineered to hold up under real use.

04  /  Work & proof

Shipped, not promised.

Work the studio has built and verified. Every number below is measured, not claimed.

Vibe-Audit — security auditor for vibe-coded apps

OPEN SOURCE  /  APPLIED AI

A security auditor for apps built with Lovable, Bolt and Supabase. It checks 9 areas — stack, secrets, data security, auth, payments, flows, data structure, code quality, deploy — and returns a graded report with plain-English fixes.

  • 1,063 lines of Python, standard library only
  • 09 check areas, graded 0–100
  • $49 per audit — first 5 free

github.com/inertiastudiospakistan/vibe-audit Read the method on Dev.to

Hospital management information system

CUSTOM SOFTWARE  /  HEALTHCARE

A multi-tenant hospital system: patient registration, OPD visits, billing, lab, pharmacy, HR and reporting — each module toggled per tenant, with dependencies resolved automatically. FastAPI backend, React frontend. Under construction.

  • 14 modules, dependency-gated per tenant
  • 02 stacks — FastAPI + React

Android apps — built and verified

MOBILE  /  PRODUCT

Two native Android apps, built and verified end to end. Play Store listings are in progress.

  • ClearLedger — offline-first expense tracker, build 22, 3.18 MB
  • Saudi EOS Calculator — fully offline, zero permissions, build 8, 3.35 MB
  • 36 target SDK on both builds

Model-routing infrastructure

AI INFRASTRUCTURE

A routing gateway that puts free AI models behind one interface — score-based routing, circuit breakers, and OpenAI- and Anthropic-compatible adapters. It is how the studio keeps AI work affordable.

  • 199 endpoints tracked
  • 32 enabled and live-tested
